# Google Sans на Samsung OneUI 8.5 без zFont

## Короткий ответ

Обычный файл `GoogleSans-Regular.ttf` нельзя выбрать как системный шрифт в стоковой OneUI 8.5. Это ограничение OneUI, а не признак поврежденного файла.

Samsung официально разрешает добавлять системные шрифты через **Galaxy Store**: **Настройки → Дисплей → Размер и стиль шрифта → Стиль шрифта → Загрузить шрифты**. Если установленный пакет показывает ошибку «Шрифт не поддерживается», Samsung рекомендует обновить его из Galaxy Store; если обновления нет, текущая версия ПО его не поддерживает.

Официальная инструкция Samsung: [как изменить стиль шрифта](https://www.samsung.com/ru/support/mobile-devices/how-can-i-change-the-font-size-and-style-on-samsung-galaxy/).

## Вариант 1 — без root: Google Sans в A15 Launcher

Это рабочий вариант из данного проекта. Шрифт применяется к часам, поиску и названиям приложений в лаунчере, но не меняет текст в настройках OneUI и других приложениях.

1. Соберите и установите A15 Launcher из каталога `launcher/`.
2. Назначьте **A15 Launcher** домашним приложением.
3. На главном экране нажмите **Aa Import font**.
4. Выберите скачанный файл `.ttf` или `.otf`.
5. Лаунчер перезапустится и применит шрифт из своего защищенного хранилища.

Для первого импорта лучше выбрать обычное начертание `Regular`. Жирный текст лаунчер создаст автоматически.

## Вариант 2 — без root: максимально похожий системный шрифт

Если важнее единый шрифт во всей системе, установите **Samsung Sans** из Galaxy Store. Он поддерживается штатным механизмом OneUI и не требует обходов:

1. Откройте **Настройки → Дисплей → Размер и стиль шрифта → Стиль шрифта**.
2. Нажмите **Загрузить шрифты**.
3. Установите **Samsung Sans**.
4. Вернитесь в **Стиль шрифта** и выберите его.

Официальная карточка: [Samsung Sans в Galaxy Store](https://galaxystore.samsung.com/detail/com.monotype.android.font.samsungsans).

## Почему APK с TTF обычно не работает

OneUI принимает не произвольный APK с файлом шрифта, а совместимый пакет шрифта из доверенного механизма Samsung/FlipFont. Самостоятельная упаковка `GoogleSans-Regular.ttf` в APK не делает пакет доверенным. На OneUI 8/8.5 система обычно показывает «Шрифт не поддерживается».

Не устанавливайте «разблокировщики шрифтов» из случайных APK, Telegram-архивов или файловых обменников: такой APK получает обычные возможности приложения, а происхождение кода проверить сложно.

## Вариант 3 — system-wide Google Sans

Для точного Google Sans во всей системе остаются два пути:

- поддерживаемый пакет Google Sans из Galaxy Store, если он когда-либо появится для вашей модели/региона;
- systemless-модуль Magisk/KernelSU из каталога `module/`, что уже требует разблокировки загрузчика и root.

Root-вариант может стереть данные при разблокировке загрузчика, навсегда изменить Knox Warranty Bit и нарушить работу Samsung Wallet, Secure Folder или банковских приложений. Для Galaxy A15 разумный порядок: сначала A15 Launcher, затем Samsung Sans; root — только если системный шрифт важнее функций Knox.

## Как удалить импортированный шрифт из лаунчера

Очистите данные A15 Launcher: **Настройки → Приложения → A15 Launcher → Память → Очистить данные**. Это также сбросит настройки самого лаунчера, но не затронет OneUI Home и системные данные.
