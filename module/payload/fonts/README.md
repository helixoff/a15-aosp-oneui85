# User-supplied fonts

The rootless launcher can import one TTF/OTF directly. This directory is only for the optional root module.

Before packaging that module, add legally obtained files named:

- `GoogleSans-Regular.ttf`
- `GoogleSans-Medium.ttf`
- `GoogleSans-Bold.ttf`
- `GoogleSans-Italic.ttf` (optional)

Font binaries are ignored by Git and must not be committed.
